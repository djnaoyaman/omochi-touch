# OMOCHI TOUCH

An interactive art playground featuring OMOCHI. Twenty-four original procedural art series, eight palettes, six photographic cutouts and twenty-four framed photographs. Arrange, pinch to resize, twist to rotate and layer images; compositions stay in the browser and can be exported as PNG.

Includes thirty selections from CRATE DIGGIN’, Premium Cuts Listed and SUBURBIA CLASSICA. A visible YouTube player loads without autoplay; playback starts when the visitor taps its native play button. Images are not uploaded. Music is not included in PNG exports.

Credit: 宮崎直哉 — https://djnaoyaman.github.io/profile.html

Artwork is independently created, inspired by artistic movements; no official museum or movement-organization affiliation is claimed. OMOCHI photographs are non-generatively masked and color-adjusted without changing the subject's geometry. Photograph copyrights remain with their owner; repository visibility does not grant a license to reuse them. Nimbus Sans font license: `assets/FONT-LICENSE.txt`.

Static HTML/CSS/JavaScript; no build step. Serve this directory or enable GitHub Pages from the repository root.

Original outlined wordmark uses Bebas Neue and Allura under SIL OFL 1.1. License notices: `assets/BebasNeue-OFL.txt` and `assets/Allura-OFL.txt`. Photo-only home-screen icons are intentionally unchanged.

The user-provided Google tag (G-Z6WH0VTYBB) is directly installed in the HTML head. The script loads on page open; a browser-local opt-out disables analytics collection, and existing declined preferences are retained. Advertising signals are disabled. Only allowlisted feature events are sent, never typed text, images or placement coordinates. PNG generation and download clicks are distinct; music selections are not playback confirmation. Step-specific UI sounds are automatic, with a global ON/OFF control.

Precise small cutouts have per-asset size caps to protect source detail (the added N05 and N04 silhouettes are limited to approximately280CSSpx on its longest side at the maximum canvas display size).

Default cutout: original fourth cutout (cut11.png, stable asset index 9), shown first. Existing saved compositions retain their asset indices.
